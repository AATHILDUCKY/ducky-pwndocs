# Welford Systems VM

Web-based security reporting suite built with Next.js and React.

## Run Locally

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`

## Production Build

1. Build the app: `npm run build`
2. Start production server: `npm run start`

## Data Persistence

Application data is stored in browser local storage (`ducky-pwn-docs:web-store:v1`).

Do not commit real SMTP credentials. Use `.env.example` as a template.
